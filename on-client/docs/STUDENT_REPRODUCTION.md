## 5. 학생 직접 재현 기록

「내가 직접 확인한 재현 기록」은 학생이 자기 PC에서 직접 한 결과만 적는 칸입니다. 학생은 2026-10-26에 원래 프로젝트 폴더 밖의 빈 폴더(`Downloads` 아래의 새 폴더)에서 아래 절차를 직접 실행했습니다. AI 실행 결과를 학생 실행 결과로 옮겨 적지 않습니다.

결과는 두 가지로 구분해 적었습니다. 「출력 첨부」는 학생이 PowerShell의 출력을 그대로 전달해 이 문서에서 대조할 수 있는 결과입니다. 「학생 진술」은 학생이 확인했다고 전달했지만 출력이나 캡처를 전달하지 않아 이 문서에서 대조하지 못한 결과입니다. 시각은 학생이 분 단위로 기록하지 않아 날짜만 적었습니다.

학생이 따라 한 절차(새 빈 폴더를 만든 뒤 그 폴더에서 PowerShell을 엽니다):

```powershell
git clone https://github.com/HTH-0/choi-bujang-secret-vault.git hth
cd hth
git checkout 0815886b7ecc15621cb1b245f1f5f50dee26f83c
git rev-parse HEAD
cd on-client
node -v
npm run check
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\start-alekov.ps1 -Port 5191
```

브라우저에서 `http://127.0.0.1:5191/`을 열어 확인한 뒤 PowerShell 창에서 `Ctrl+C`로 종료하고 같은 명령을 한 번 더 실행합니다.

| 20 | 설치 패키지 조회 결과(`renderVulnerabilities`) | 모의(5종 상태, 정확한 버전, 일부 조회 실패에서 ID 유지), 예제 화면의 `not_configured`, 학생 화면 | `a4e2443`, 통과(전달) | 실제 패키지 행과 `package-lock.json` 버전 비교: 허용 패키지와 lock 파일이 이 프로젝트에 없음 |
| 21 | 학생 실행 설명서와 구성도 | 문서와 코드 대조 99건(AI 실행), 학생이 새 PowerShell 창에서 실행해 시작 신호와 화면 확인 | `0815886`, 합격(전달) | macOS·Linux, Node.js 24.19.0 미확인 |

예제 화면과 모의 점검의 성공은 실제 시스템 연결의 성공이 아닙니다. 이 표의 「통과」는 ALEPH 서버 AI의 원문 검토 결과이며, 서버가 코드를 실행해 확인한 것이 아닙니다.

## 8. 버전과 지원 범위

| 항목 | 내용 |
|---|---|
| 앱 | HTH 보안 Agent. ALEKOV 시작 틀 0.2.11(`on-client/package.json`) 위에 학생 구현 13~20단계와 문서 21~22단계를 추가했습니다. |
| 릴리스 상태 | **검증 중인 버전**입니다. 새 버전 번호는 붙이지 않았습니다. 22단계 통과는 원문 검토 기준의 수료이며 실제 운영 인증이나 v1.0 자동 인증이 아닙니다. |
| 지원 환경 | Windows와 Node.js 22~24. 실행해 본 환경은 Windows 11 Pro와 Node.js v24.21.0입니다. |
| 지원하지 않거나 확인하지 않은 환경 | macOS, Linux, Node.js 22·23, 24.19.0, Chrome 외 브라우저는 실행해 보지 않았습니다. |

### 8.1 누락·미해결 사항

| 사항 | 상태 |
|---|---|
| 실제 계정 연결(native), SDP 연결 | 담당자가 준비하는 설정이 없어 연결하지 않았습니다. 미확인 |
| AI 연결 점검 성공, 실제 AI 사건 설명 | 운영 측 앱 권한이 준비되지 않아 `ON_AI_PROVISIONING_PENDING`(권한 준비 중)만 확인했습니다. 미확인 |
| 보안 조치의 실제 집행(19단계 실집행) | 연결이 준비되지 않았고 시험 삼아 요청하지 않았습니다. 미완료 |
| 실제 패키지 조회 | 허용 패키지 설정과 `package-lock.json`이 없어 `not_configured`만 확인했습니다. 미확인 |
| `npm run test:package`의 실패 1건 | 기대 파일 목록과 실제 `api/` 파일 목록이 다릅니다(4장 11번). 원인을 조사하지 않았고 해결하지 않았습니다. |
| `restore/safe-policy.json`이 오래됨 | 사본이 XDR 규칙과 `/api/restore` 경로 추가 이전 것이어서 `restore:preview`가 차이를 표시합니다. 사본은 갱신하지 않았습니다. |
| 학생 직접 재현의 일부 항목 | 5장에서 「학생 진술」로 표시한 항목(`npm run check`, 브라우저 화면, 종료와 재실행, 원래 폴더 보존)은 출력이나 캡처가 없어 대조하지 못했습니다. |

## 9. 이 문서가 증명하지 않는 것

- AI 보조 도구의 실행 결과(4장)는 이 PC에서 한 번 실행한 결과입니다. 다른 PC나 다른 날의 재현을 보장하지 않습니다.
- 서버의 AI 판정은 원문을 읽은 검토이며, 서버가 새 환경에서 앱을 실행한 것이 아닙니다.
- 예제(demo) 화면의 성공은 실제 연결의 성공이 아닙니다.
