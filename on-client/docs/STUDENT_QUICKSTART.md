# HTH 앱 처음 실행 안내 (처음 보는 사람용)

이 안내는 HTH 보안 Agent 앱을 처음 받아 실행해 보는 사람이 위에서 아래로 따라 하도록 만들었습니다. 소요 시간은 약 10분입니다. 시스템 구성도와 13~20단계 구현 설명은 [STUDENT_RUNBOOK.md](STUDENT_RUNBOOK.md)에 있습니다. 그 문서는 21단계 제출 당시의 기록이라 현재 기능 일부가 빠져 있고, 이 안내가 현재 상태 기준입니다.

## 화면의 값을 구분하는 법

| 표시 | 뜻 |
|---|---|
| 「예시 값(예제 자료, 실제 조회 결과 아님)」, 「예제 자료」 | 설명용 가상 자료입니다. 예제 모드(`-Demo`)에서만 나옵니다. 실제 내 PC나 회사 시스템의 값이 아닙니다. |
| 「실측」, 「불러온 파일 값(실측)」 | 이 PC에서 직접 잰 값입니다. 잰 시각(한국 시각)과 단위가 함께 나옵니다. |
| 「확인 불가」 | 읽지 못한 값입니다. 숫자를 만들어 채우지 않고 이유와 「다음에 할 일」을 보여 줍니다. |
| 「SDP 미연결」 | 회사 시스템(SDP)에 연결하지 않은 상태입니다. 기본 실행에서는 정상입니다. |

「확인 불가」는 뜻이 두 가지입니다. 상태 카드와 내 PC 칸의 「확인 불가」는 이 앱이 **값을 읽지 못했다**는 표시이고, 업무 앱 화면의 판정 「확인 불가」는 **접속 판정의 결과**입니다. 칸 위쪽의 「예제 자료」와 카드의 「예시 값」은 같은 뜻입니다.

## 제공 기능과 직접 만든 부분

| 구분 | 제공(수정하지 않음) | 직접 만든 것(`on-client/student/` 안) |
|---|---|---|
| 화면 틀 | 상단 바, 왼쪽 메뉴, 제공 카드, 학생 칸의 제목 줄, 「다시 불러오기」 버튼, 색 테마, `public/`과 `src/` 전체 | 없음 |
| ① 상태 카드와 SDP | 기기·세션·알림·진단 자료와 그 조회 | 4개 카드로 집계, 값마다 출처 표시, 읽지 못하면 「확인 불가」, SDP 상태를 PC 점검과 분리해 표시(「SDP 미연결」) |
| ② 내 PC 상태 | 학생 코드가 부를 수 있는 조회 주소 5개(`/api/me` 등) | 응답 시간과 메모리 실측, 직전 측정과 비교, 실패한 항목과 「다음에 할 일」, 「다시 조회」와 대기 표시 |
| ③ 내 PC 점검 | 없음(이 앱 판에는 제공 「내 PC 상태」 카드와 `/api/pc/status`가 없습니다) | 읽기 전용 수집 스크립트(`collect-pc-info.ps1`), 파일 검증과 표시, 직전 파일과 비교, 실패 때 이전 값 분리 |
| 맨 위 요약 | 학생 칸 8개의 자리 | 가장 위 학생 칸의 「핵심 3가지 요약」과 바로가기, 접힌 설명, 추이 막대(SVG) |
| 13~20단계 | 화면 함수의 자리와 호출 방식 | 이전 단계에서 구현한 8개 표시 함수(이번 정리에서 지우지 않음) |

## 1. 준비물

1. Windows 10 또는 11. 실행 도구가 PowerShell(`.ps1`)이어서 Windows 기준입니다. macOS와 Linux는 확인하지 못했습니다.
2. Node.js 22~24(수업 기준 24.19.0). PowerShell에서 `node -v`를 입력해 버전이 나오면 준비된 것입니다. 「node을(를) 찾을 수 없습니다」처럼 나오면 https://nodejs.org 에서 설치한 뒤 PowerShell 창을 새로 엽니다.
3. Git(내려받기용). 없으면 GitHub 저장소 화면의 「Code」 메뉴에서 ZIP으로 받아 풀어도 됩니다.
4. 브라우저. 화면 점검은 Chrome으로 했습니다. 다른 브라우저는 확인하지 못했습니다.

## 2. 내려받고 앱 폴더로 이동

PowerShell을 열고 아래를 한 줄씩 실행합니다. 폴더 경로에 한글이나 공백이 있어도 실행됩니다(확인함).

```powershell
git clone https://github.com/HTH-0/choi-bujang-secret-vault.git
cd choi-bujang-secret-vault\on-client
```

프롬프트가 `...\on-client>`로 끝나면 앱 폴더입니다. 이 앱 폴더에서 아래 모든 명령을 실행합니다. 프로젝트 맨 위 폴더(`choi-bujang-secret-vault>`)에서 실행하면 막힙니다(8장 참고).

## 3. 실행

아래 명령을 한 줄 전체로 복사해서 실행합니다. 끝이 `.ps1`이어야 합니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\start-alekov.ps1
```

`-ExecutionPolicy Bypass`는 이번 실행에만 적용되고 PC 설정은 바꾸지 않습니다. 정상이면 아래처럼 나옵니다. 첫 줄은 Node.js 버전이 24.19.0이 아닐 때만 나옵니다.

```text
참고: 지금 Node.js 는 v24.21.0 입니다. 수업 기준은 v24.19.0 입니다.
케셰브 연결 확인: http://127.0.0.1:5189
케셰브가 켜졌습니다. 브라우저에서 http://127.0.0.1:5189/ 을 여세요.
서버가 응답한 것만 확인했습니다. AI 연결 상태는 화면에서 따로 확인해 주세요.
끄려면 이 창에서 Ctrl+C 를 누르세요.
```

이 창은 서버가 쓰는 창이므로 닫지 말고 그대로 둡니다. 다른 명령은 새 PowerShell 창에서 실행합니다.

| 하고 싶은 일 | 명령(앱 폴더에서) |
|---|---|
| 예제 자료로 화면 보기 | 위 명령 끝에 ` -Demo`를 붙입니다. 실제 연결이나 성취가 아닙니다. |
| 5189 포트가 사용 중일 때 | 위 명령 끝에 ` -Port 5190`을 붙이고, 아래 4장의 주소도 5190으로 바꿉니다. |
| 창 없이 뒤에서 실행 | 위 명령 끝에 ` -Background`를 붙입니다. 안내되는 프로세스 번호를 적어 둡니다. |
| 학생 파일 문법 검사 | `node --check student/extension.mjs`. 오류가 없으면 아무것도 나오지 않습니다. `npm run check`도 같은 검사입니다. |

## 4. 브라우저에서 확인

1. `http://127.0.0.1:5189/`을 엽니다(포트를 바꿨으면 그 번호). 코드를 고친 뒤에는 `Ctrl+F5`로 새로고침합니다.
2. 「보호 현황」 탭의 가장 위 학생 칸(「학생 구현 표시 · renderIdentity」)에 「핵심 3가지 요약」이 있습니다. ① 상태 카드와 SDP, ② 내 PC 상태, ③ 내 PC 점검의 현재 상태가 한 줄씩 보이고, 각 버튼을 누르면 아래의 해당 칸(「학생 상태·알림 표시」)으로 이동합니다. 그 칸 맨 위에도 「핵심 3가지 바로가기」 버튼 3개가 있어서 ①②③ 사이를 오갈 수 있습니다.
3. 기본 실행의 정상 모습: 오른쪽 위 「연결 없음」 배지, 「SDP 미연결」 카드, 상태 카드의 「확인 불가」. 서버를 회사 시스템에 연결하지 않았으므로 정상입니다.
4. `-Demo` 실행의 정상 모습: 「예제 자료」 표시와 「예시 값」 표시가 붙은 카드(기기 1대, 세션 1개, 알림 2건)와 「예제 자료(SDP 아님)」 카드.

키보드만으로도 쓸 수 있습니다. Tab으로 이동하고 Enter나 Space로 누릅니다. 「…보기」라고 적힌 줄은 접힌 설명입니다. Enter나 Space로 펼치고 접으며, 화면이 다시 그려져도 펼친 상태가 유지됩니다. 등록 기기, 현재 세션, 알림, 진단 정보(기존 상태 표시)는 「기존 상태 표시 보기」 안에 그대로 있습니다.

## 5. 내 PC 상태 (② 칸)

「내 PC 상태 측정」 버튼을 누르면 앱의 조회 주소 5개를 한 번씩 부르고 응답 시간을 잽니다. 한 번 끝나면 버튼이 「다시 조회」로 바뀌고, 두 번 이상 하면 직전과 비교하는 표가 나옵니다. CPU 사용률과 디스크 남은 공간은 브라우저가 알려 주지 않아 항상 「확인 불가」입니다. 기본 실행에서는 조회가 모두 「실패」(`ENGINE_NOT_CONNECTED`)로 나오는 것이 정상이며, 실패한 항목마다 「다음에 할 일」이 표시됩니다.

## 6. 내 PC 점검 (③ 칸)

네트워크 구성, 방화벽, Windows 기록의 경고·오류 건수를 보여 줍니다. 이 건수는 침해나 공격 탐지 결과가 아닙니다. 브라우저는 이 값을 직접 읽을 수 없어서, 읽기 전용 수집 스크립트가 만든 파일을 불러옵니다. 관리자 권한은 필요 없고 설정은 바꾸지 않으며, 실제 IP 주소, MAC, 컴퓨터 이름은 수집하지 않습니다.

1. 새 PowerShell 창을 열고 앱 폴더로 이동한 뒤 실행합니다. 끝이 `.ps1`이어야 합니다.

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File .\student\collect-pc-info.ps1
   ```

   `saved: ...` 줄이 나오면 `%TEMP%\hth-pc-info.json` 파일이 만들어진 것입니다.
2. 브라우저의 ③ 칸에서 「PC 점검 파일 불러오기」 버튼을 누릅니다.
3. 파일 선택 창 위쪽 주소칸에 `%TEMP%`를 입력하고 Enter를 누른 뒤 `hth-pc-info.json`을 고릅니다. 폴더가 먼저 나열되어 파일은 목록 맨 아래에 있습니다. 안 보이면 아래로 내리거나 「파일 이름」 칸에 `hth-pc-info.json`을 직접 입력합니다.
4. 값이 나오면 버튼이 「다시 조회(파일 다시 고르기)」로 바뀝니다. 1번을 다시 실행한 뒤 같은 방법으로 한 번 더 고르면 비교 표가 나옵니다. 비교 기록은 브라우저 탭의 메모리에만 있으므로 탭을 새로고침하면 사라집니다.

## 7. 끄기

서버 창에서 `Ctrl+C`를 누릅니다. `-Background`로 실행했다면 안내된 프로세스 번호의 `node`를 작업 관리자에서 종료합니다. 종료 뒤 주소가 열리지 않으면(`ERR_CONNECTION_REFUSED`) 꺼진 것입니다.

## 8. 막혔을 때

아래 문구는 영어 Windows에서 실제로 나온 출력입니다. 한국어 Windows에서는 같은 뜻의 한국어 문구로 나올 수 있습니다.

| 나온 문구 | 원인 | 할 일 |
|---|---|---|
| `The argument '.\tools\start-alekov.ps1' to the -File parameter does not exist` (한국어: 「-File 매개 변수에 대한 인수 …이(가) 없습니다」) | 앱 폴더가 아닌 곳에서 실행함 | 프롬프트가 `...\on-client>`인지 확인하고 아니면 `cd on-client`로 이동한 뒤 다시 실행합니다. |
| `npm error Missing script: "start"` (또는 `"demo"`, `"check"`) | 프로젝트 맨 위 폴더에서 `npm`을 실행함 | `cd on-client`로 앱 폴더에 들어간 뒤 다시 실행합니다. |
| `Processing -File '...collect-pc-info.ps' failed because the file does not have a '.ps1' extension` (한국어: 「파일에 '.ps1' 확장명이 없으므로…」) | 명령을 끝까지 복사하지 못해 `.ps1`의 `1`이 빠짐 | 명령 전체를 한 줄로 다시 복사합니다. 끝이 `.ps1`이어야 합니다. |
| `npm : File ...npm.ps1 cannot be loaded because running scripts is disabled on this system` | PC 설정이 스크립트 실행을 막아 `npm` 명령이 막힘 | PC 설정을 바꾸지 말고, 3장의 권장 명령(`-ExecutionPolicy Bypass`), 예제 화면은 ` -Demo`, 문법 검사는 `node --check student/extension.mjs`를 씁니다. 이 세 가지는 같은 상태에서도 실행되는 것을 확인했습니다. |
| 「포트 5189 를 다른 프로그램이 쓰고 있습니다」 | 이미 켜 둔 서버가 있거나 다른 프로그램이 포트를 씀 | 그 프로그램은 끄지 말고 ` -Port 5190`을 붙여 실행합니다. 이때 종료 코드는 1입니다. |
| 「Node.js 가 없습니다」 | Node.js 미설치 | https://nodejs.org 에서 설치하고 PowerShell을 새로 연 뒤 다시 실행합니다. |
| 「지금 Node.js 는 vXX 입니다」 + 멈춤 | Node.js가 22 미만이거나 25 이상 | Node.js 22~24를 설치하고 PowerShell을 새로 엽니다. |
| 브라우저 `ERR_CONNECTION_REFUSED` | 서버가 꺼져 있음 | 3장의 실행 명령을 다시 실행합니다. |
| 학생 칸에 「학생 구현 대기」가 남음 | 브라우저가 예전 화면을 보여 줌 | `node --check student/extension.mjs`로 문법을 확인하고, 서버를 껐다 켠 뒤 `Ctrl+F5`를 누릅니다. |
| ② 칸의 「실패한 항목 5개 / 5개」 | 기본 실행은 회사 시스템에 연결하지 않음 | 정상입니다. 예제 화면은 ` -Demo`로 봅니다. 실제 연결은 담당자 안내를 받은 뒤에만 설정합니다. |
| ③ 칸에 「불러오지 못했습니다(확인 불가)」 | 파일이 아니거나 형식이 맞지 않음, 시각 이상 | 6장 1번 명령으로 새 파일을 만든 뒤 「다시 조회」를 눌러 다시 고릅니다. 이전에 불러온 값은 「마지막으로 성공한 점검 값 보기」 안에 접혀 있고 현재 값이 아닙니다. |
| ③ 칸의 「주의 · 오래된 값」 | 불러온 파일이 60분보다 오래됨 | 6장 1번 명령을 다시 실행해 새 파일을 고릅니다. |
| Security 기록 「확인 불가」 | 관리자 권한이 필요한 항목이라 읽지 않음 | 정상입니다. 이 앱은 권한을 올리지 않습니다. |

## 9. 이 안내가 확인하지 못한 것

- Node.js 24.19.0, macOS, Linux, Chrome이 아닌 브라우저, 한국어가 아닌 Windows의 한국어 오류 문구는 실행해 보지 못했습니다.
- 회사 보안 프로그램이나 그룹 정책이 PowerShell 실행을 막는 PC는 확인하지 못했습니다.
- 실제 SDP 연결, AI 연결, 패키지 조회는 담당자 설정이 필요해 이 안내의 범위 밖이며 확인하지 않았습니다.
- 화면 읽기 프로그램(NVDA 등)의 사용성은 검증하지 않았습니다.
- 이 안내를 처음 보는 사람이 실제로 따라 해 본 시험은 하지 않았습니다. 작성자가 새 폴더 사본에서 명령을 순서대로 실행해 본 시험만 했습니다.
- 비밀번호, 토큰, API 키, 개인키는 이 안내와 화면, 커밋에 넣지 않습니다.

## 10. 화면을 꾸민 방식과 바꾸지 않은 것

- **바꾼 곳:** 학생 칸 안쪽뿐입니다. 상단 바, 왼쪽 메뉴, 제공 카드, 칸 제목 줄, 색 테마, `public/`, `src/`는 바꾸지 않았습니다.
- **방식:** 제공 클래스(`card`, `grid-2`, `state`, `tag`, `muted`, `btn`, `plain-list`)와 접기(`details`), 추이 막대(SVG)로 만들었습니다. 보안 정책이 `style` 속성과 `<style>` 요소를 막으므로 쓰지 않았고, 자바스크립트로 지정한 스타일은 큰 숫자 글자 크기와 카드 열 배치를 위한 4줄뿐입니다. 이 4줄이 가이드가 명시한 방식은 아닙니다.
- **정직한 구분:** 읽지 못한 값은 숫자를 만들지 않고, 실패하면 이전 값을 현재 값처럼 남기지 않고(접힌 「마지막으로 성공한 점검 값」으로 분리), 예시 값은 「예시 값」 표시가 붙은 곳에만 있습니다.

같은 방법(헤드리스 Chrome, 창 높이 805px)으로 이전 버전(커밋 `b629e33`)과 지금을 이 PC에서 잰 값입니다(실측, 2026-10-30).

창 너비를 바꿔 가며(1024, 1100, 1280, 1366, 1536, 1920px) 잰 결과입니다(실측, 예제 모드와 기본 모드 각각 48건 검사, 모두 통과).

- 학생 칸 밖으로 삐져나간 요소는 0개이고, 학생 칸 안의 가로 스크롤도 0px입니다.
- 「핵심 3가지 요약」의 버튼은 모든 폭에서 한 줄이고, 설명은 세 줄 모두 같은 위치에서 시작합니다.
- 상태 카드 4개는 모든 폭에서 한 줄로 나란히 있고, 출처 표시(알약)도 한 줄입니다.
- 창 너비 1024px에서 페이지 가로 스크롤이 15px 생깁니다. 제공 화면(`header.topbar`, `div.layout`, `main#main`)이 최소 너비 1024px로 정해져 있어서 세로 스크롤바 폭만큼 생기는 것이며, 학생 칸 안의 요소는 원인이 아닙니다(확인함). 이 앱은 1024px보다 좁은 창에서는 줄어들지 않습니다.
